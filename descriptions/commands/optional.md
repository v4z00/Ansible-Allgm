# Optionale Standortdienste ausrollen

Optionale Standortdienste ausrollen

Aufruf: `bin/control optional [Optionen]`.

Vorhandene Kurzformen: `optional`.

Feature: kein zusaetzlicher Feature-Schalter. Die aktuelle Aktivierung prueft weiterhin Control.

Voraussetzungen laut Registry:
- `lib/control/helpers.sh`
- `playbooks/optional.yml`
